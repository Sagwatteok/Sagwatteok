# GitHub Stats Transparent templates

SVG templates from [kyu0918/github-stats-transparent](https://github.com/kyu0918/github-stats-transparent), based on [rahul-jha98/github-stats-transparent](https://github.com/rahul-jha98/github-stats-transparent) and [jstrieb/github-stats](https://github.com/jstrieb/github-stats). Licensed under GPL-3.0; see LICENSE in this directory.

Modifications: overview rows reduced to Total Commits, Lines of Code Changed, and Repositories with Contributions; animation delays adjusted; card headings changed to the profile's lavender theme. The local generator fills these templates using public GitHub data. Total Commits counts authored commits, rather than the upstream all-contribution counter. Languages aggregate bytes in owned non-fork public repositories. Merge commits count as commits but are excluded from changed-line totals. Identical commit SHAs are counted once.
